2. 좌표계, 좌표변환 설계
	(1) 아래 조건 하에 신호처리 결과를 수신 받아 데이터 처리 진행 후 처리 결과를 레이다 운용 전시기에 전달하기까지 과정에 필요해 보이는 좌표계를 선정하고 해당 좌표계 간의 좌표변환 과정을 서술하시오.
		- 조건 1: 플랫폼은 해상에서 운용되는 함선이며 레이다는 고정형 안테나임
		- 조건 2: 레이다 안테나는 함선 heading 기준 시계방향 90도를 향해 바라보고 있으며 함선 무게 중심으로부터 30m 뒤, 높이는 10m 높게 설치되어 있음
		- 조건 3: INS(항법장치)는 플랫폼 무게중심과 축이 일치한 상태로 설치되어 있음
		- 조건 4: 신호처리에서 제공하는 데이터 처리 입력 값은 안테나 기준 거리, 방위각, 고각 성분
		- 조건 5: 데이터 처리는 로컬 좌표계 상에서 수행
		- 조건 6: 데이터 처리 결과는 통제제어에 위/경/고도 좌표계 성분과 안테나 좌표계(극 좌표계) 성분으로 제공해야 함
		- 설계 내용: 단계 별로 필요한 좌표계 선정 후 선정한 이유와 함께 좌표계 간 좌표 변환 과정 서술

3. C 코딩을 통한 해당 내용 검증
	(2) 앞서 설계한 좌표계간의 좌표변환 코드 구현 후 데이터 처리 입력 값에 대한 최종적인 출력 값을 확인 하시오.
		1. 신호처리에서 제공하는 데이터 입력 값
			- Slant Range: 20km
			- Azimuth : 30도
			- Elevation: 0도
		2. 플랫폼 위치 및 자세 정보(플랫폼은 이동하지 않고 고정되어 있음)
			- 위도: 36.408도
			- 경도: 127.307도
			- 고도: 0m
			- 자세각(r,y,p): 0도, 45도, 0도
		3. 데이터처리 최종 출력 값
			- 표적 위도/경도/고도
			- 표적 안테나 기준 시선거리, 방위각, 고각
